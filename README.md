# 🔐 EnHac - File Encryptor Pro

<div dir="rtl">

## 📋 نظرة عامة

**EnHac** هو برنامج تشفير متقدم للملفات والمجلدات يعمل على نظام ويندوز. يتيح لك حماية بياناتك الحساسة عن طريق تحويلها إلى صيغة غير قابلة للقراءة بدون كلمة المرور الصحيحة.

## 🚀 التثبيت والتشغيل

### المتطلبات
- **Windows 10/11** أو أحدث
- **.NET 10.0 SDK** أو أحدث
- **Visual Studio 2022** أو أحدث (للتطوير)

### خطوات التشغيل

```bash
# 1. استنساخ المشروع
git clone https://github.com/yourusername/EnHac.git

# 2. الدخول إلى مجلد المشروع
cd EnHac

# 3. بناء المشروع
dotnet build

# 4. تشغيل البرنامج
dotnet run
```

### التثبيت من Visual Studio

1. افتح **Visual Studio 2022**
2. اختر **File → Open → Project/Solution**
3. حدد ملف `EnHac.csproj`
4. اضغط **F5** للتشغيل

## 📖 دليل الاستخدام

### تشفير ملف واحد

1. اختر تبويب **"📄 ملف واحد"**
2. اضغط **"📁 تصفح"** أو اسحب الملف إلى المنطقة المخصصة
3. أدخل **كلمة المرور** وتأكيدها
4. (اختياري) حدد **"حذف الملف الأصلي"** إذا أردت
5. اضغط **"🔒 تشفير الملف"**
6. انتظر حتى اكتمال العملية

### فك تشفير ملف

1. اختر تبويب **"📄 ملف واحد"**
2. حدد الملف المشفر (`.encrypted`)
3. أدخل **نفس كلمة المرور** المستخدمة للتشفير
4. اضغط **"🔓 فك تشفير الملف"**

### تشفير مجلد كامل

1. اختر تبويب **"📁 مجلد"**
2. حدد **مجلد المصدر**
3. حدد **مجلد الإخراج**
4. أدخل **كلمة المرور**
5. (اختياري) حدد **"حذف الملفات الأصلية"**
6. اضغط **"🔒 تشفير المجلد"**

### فك تشفير مجلد

1. اختر تبويب **"📁 مجلد"**
2. حدد المجلد الذي يحتوي على ملفات `.encrypted`
3. حدد **مجلد الإخراج**
4. أدخل **كلمة المرور**
5. اضغط **"🔓 فك تشفير المجلد"**

## ⚠️ تحذيرات مهمة

### 🔴 تنبيهات أمنية

> **⚠️ لا تنسى كلمة المرور أبداً!**
> بدون كلمة المرور الصحيحة، **لا يمكن** استعادة الملفات المشفرة أبداً.

> **⚠️ احتفظ بنسخة احتياطية**
> قبل تشفير الملفات المهمة، احتفظ بنسخة احتياطية في مكان آمن.

> **⚠️ حذف الملفات الأصلية**
> خيار "حذف الملف الأصلي" **لا يمكن التراجع عنه**. تأكد قبل استخدامه.

### 📋 نصائح لكلمات المرور

| المستوى | المعايير | مثال |
|---------|----------|------|
| ❌ ضعيفة | أقل من 8 أحرف | `123456` |
| ⚠️ متوسطة | 8+ أحرف وأرقام | `Password123` |
| ✅ قوية | 12+ أحرف ورموز | `My$ecureP@ss2024!` |

## 🔍 استكشاف الأخطاء

### مشكلة: "لا توجد صلاحية"

**الحل:**
- شغل البرنامج **كمسؤول** (Run as Administrator)
- تجنب تشفير مجلدات النظام (`Windows`, `Program Files`)
- انقل الملفات إلى مجلد المستخدم (`Desktop`, `Documents`)

### مشكلة: "فشل فك التشفير"

**الأسباب المحتملة:**
- كلمة مرور خاطئة
- الملف تالف أو معدل
- الملف غير مشفر بهذا البرنامج

**الحل:**
- تأكد من كلمة المرور الصحيحة
- جرب تشفير ملف اختبار ثم فك تشفيره
- تأكد من أن الملف ينتهي بـ `.encrypted`

### مشكلة: "الملف قيد الاستخدام"

**الحل:**
- أغلق البرنامج الذي يستخدم الملف
- انتظر حتى انتهاء نسخ/نقل الملف
- أعد تشغيل الكمبيوتر إذا استمرت المشكلة
